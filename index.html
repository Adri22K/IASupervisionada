DEFINIÇÃO

O que é aprendizado supervisionado?

É uma abordagem de aprendizado de máquina em que o modelo aprende a partir de exemplos que possuem uma resposta conhecida, chamada de rótulo, para posteriormente fazer previsões sobre novos dados.

◎
CLASSIFICAÇÃO

“Qual categoria?”

Prevemos uma classe, como spam / normal ou qualidade do ar adequada / inadequada.

Entrada→SPAM
↗
REGRESSÃO

“Qual valor?”

Prevemos um valor numérico, como a concentração futura de um poluente ou a temperatura.

PM2.5→35 µg/m³
02

DO DADO À PREVISÃO

Como o modelo aprende?

O processo pode ser entendido em cinco passos.

01
▦

Coletamos

Reunimos exemplos que representam o problema que queremos resolver.

02
🏷

Rotulamos

Associamos cada exemplo a uma resposta conhecida.

03
✦

Treinamos

O algoritmo procura padrões que relacionam entradas e respostas.

04
◌

Testamos

Avaliamos o modelo usando dados que não foram usados no treinamento.

05
⌁

Prevemos

O modelo recebe um novo dado e produz uma previsão.

EM UMA LINHA

dados + rótulos → treinamento → modelo → previsão

Intuição antes da matemática.
03

ALGORITMO EM FOCO

Árvore de decisão.

Uma árvore de decisão aprende regras simples do tipo “se... então...” para chegar a uma previsão.

Ela pode ser usada tanto em classificação quanto em regressão e é especialmente interessante para uma primeira explicação porque sua estrutura pode ser visualizada.

VISUAL • INTERPRETÁVEL • SUPERVISIONADO
PM2.5 > 30 µg/m³?
NÃO
❌ NÃO
SIM
PM10 > 50 µg/m³?
NÃO
❌ NÃO
SIM
✓ SIM
⚠️
Nenhuma árvore cresce infinitamente.

Árvores muito complexas podem se ajustar demais aos dados de treinamento. Esse problema é conhecido como overfitting.

04

AGORA VAMOS CODIFICAR

Um modelo em Python.

Exemplo curto de uma árvore de decisão aplicada ao nosso projeto de qualidade do ar.

modelo.py PYTHON 
from sklearn.tree import DecisionTreeClassifier

# Dados de treinamento: [PM2.5, PM10] em µg/m³
# Valores simplificados apenas para demonstrar a IA supervisionada
X = [
    [10, 20],
    [15, 30],
    [45, 70],
    [60, 90]
]

# Respostas conhecidas
# 0 = qualidade do ar adequada | 1 = qualidade do ar inadequada
y = [0, 0, 1, 1]

# Criando o modelo
modelo = DecisionTreeClassifier(
    random_state=42
)

# Treinando o modelo com exemplos já classificados
modelo.fit(X, y)

# Novo horário: PM2.5 = 35 e PM10 = 55 µg/m³
previsao = modelo.predict([[35, 55]])

print(previsao)
O QUE ACONTECEU?
01

X contém as características dos exemplos.

02

y contém os rótulos conhecidos.

03

fit() treina o modelo com os exemplos.

04

predict() produz uma previsão para um novo dado.

ONDE PODE DAR ERRADO?

Modelos também falham.

01

Dados ruins

Se os exemplos não representam bem o problema, o modelo pode aprender padrões inadequados.

02

Poucos dados

Uma quantidade limitada de exemplos pode dificultar a identificação de padrões úteis.

03

Overfitting

Um modelo muito ajustado ao treinamento pode ter dificuldade com dados novos.

04

Viés nos dados

Padrões presentes nos dados podem influenciar o comportamento aprendido pelo modelo.
