# 🤖 Aprendizado Supervisionado

Esse projeto é para criação de um site educativo desenvolvido para apresentar, de forma visual e didática, o funcionamento da **Inteligência Artificial baseada em Aprendizado Supervisionado**.

O projeto foi desenvolvido como atividade acadêmica da matéria de **Ciência de Dados e Aprendizagem de máquina**, com foco em explicar os principais conceitos de maneira acessível, utilizando exemplos visuais e uma abordagem interativa.


## 📚 Sobre o projeto

O **Aprendizado Supervisionado** é uma abordagem de Machine Learning em que o modelo aprende a partir de dados que possuem exemplos conhecidos, chamados de dados rotulados.

Neste site, apresentamos:

* 🧠 O conceito de aprendizado supervisionado;
* 🔄 Como funciona o processo de treinamento de um modelo;
* 🌳 O funcionamento de uma Árvore de Decisão;
* 💻 Um exemplo de código utilizando Python;
* ⚠️ Limitações e cuidados no uso de modelos de Machine Learning;
* 👥 Informações sobre os integrantes responsáveis pelo projeto.

A proposta é transformar um tema técnico em uma experiência visual simples e fácil de acompanhar.


## 🗺️ Caminho do projeto

O site apresenta o desenvolvimento do processo de Machine Learning em cinco etapas:

1. **Escolha um problema**
2. **Encontre dados**
3. **Treine**
4. **Avalie**
5. **Melhore**

Essa sequência ajuda a visualizar como um problema pode ser transformado em um processo de aprendizado de máquina.


## 🌳 Algoritmo apresentado

O algoritmo utilizado como exemplo principal é a **Árvore de Decisão**.

Ela permite representar decisões por meio de uma estrutura semelhante a uma árvore, em que:

* os nós representam condições;
* os caminhos representam decisões;
* as folhas representam os resultados.

O algoritmo pode ser utilizado em tarefas de **classificação** e **regressão**.

## 🚀 Como executar o projeto

Não é necessário instalar dependências para visualizar o site.

### 1\. Clone o repositório

```bash
git clone https://github.com/Adri22K/IASupervisionada.git
```

### 2\. Entre na pasta

```bash
cd IASupervisionada
```

### 3\. Abra o site

Abra o arquivo:

```text
index.html
```

diretamente no navegador.

> Também é possível utilizar uma extensão como **Live Server** no Visual Studio Code para executar o projeto localmente.
