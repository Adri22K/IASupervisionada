DO DADO À PREVISÃO

Como o modelo aprende?

O processo pode ser entendido em cinco passos.

01
▦

Coletamos

Reunimos exemplos que representam o problema que queremos resolver.

02
🏷

Rotulamos

Associamos cada exemplo a uma resposta conhecida.

03
✦

Treinamos

O algoritmo procura padrões que relacionam entradas e respostas.

04
◌

Testamos

Avaliamos o modelo usando dados que não foram usados no treinamento.

05
⌁

Prevemos

O modelo recebe um novo dado e produz uma previsão.

EM UMA LINHA

dados + rótulos → treinamento → modelo → previsão

Intuição antes da matemática.
