Um modelo em Python.

Exemplo curto de uma árvore de decisão aplicada ao nosso projeto de qualidade do ar.

modelo.py PYTHON 
from sklearn.tree import DecisionTreeClassifier

# Dados de treinamento: [PM2.5, PM10] em µg/m³
# Valores simplificados apenas para demonstrar a IA supervisionada
X = [
    [10, 20],
    [15, 30],
    [45, 70],
    [60, 90]
]

# Respostas conhecidas
# 0 = qualidade do ar adequada | 1 = qualidade do ar inadequada
y = [0, 0, 1, 1]

# Criando o modelo
modelo = DecisionTreeClassifier(
    random_state=42
)

# Treinando o modelo com exemplos já classificados
modelo.fit(X, y)

# Novo horário: PM2.5 = 35 e PM10 = 55 µg/m³
previsao = modelo.predict([[35, 55]])

print(previsao)
O QUE ACONTECEU?
01

X contém as características dos exemplos.

02

y contém os rótulos conhecidos.

03

fit() treina o modelo com os exemplos.

04

predict() produz uma previsão para um novo dado.
